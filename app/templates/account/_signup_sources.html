GitHub

Connect to GitHub to bring in your repositories. Create a new fine-grained personal access token and give it read-only access to your organisation's repositories.

{% call collapsible(id='github-token-help') %} {% call collapsible_trigger() %}How to make the token{% endcall %} {% call collapsible_content() %}
  1. On GitHub, make sure you are acting as the correct organisation.
  2. For Repository access, choose All repositories or the repositories you want to connect.
  3. Under Permissions, find Repository permissions and set:
    • Contents to Read-only.
    • Metadata to Read-only.
  4. Under Organisation permissions, set Members to Read-only.
  5. Click Generate token and copy the new token here.
