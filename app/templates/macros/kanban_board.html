{# Shared Kanban board shell. One board markup for the whole product: every Kanban (the SAFe portfolio board, the ADM architecture board) renders this macro so the platform holds exactly one board implementation. The reuse-register `kanban-board` entry refuses a second `class="kanban-board"` anywhere outside this file. The shell owns: the board container, the sideways-scroll region that keeps the columns in one row at every width (section 26 of the recognisable-form reference — the board never stacks into one column on a phone), the column headers with their count and WIP limit, and the empty-column hint. The per card body is the caller's: the macro yields inside each column's card list via {{ caller(state) }}, so each board keeps the card its users know while sharing the shape, the move affordance and the WIP treatment. The board is driven by a sibling Alpine component (kanbanBoard() for the portfolio board, admKanbanV2() for the ADM board); both expose the same method names the shell binds to: columnCards, columnCount, wipLimit, wipCount, wipAtLimit, wipNearLimit, onDragStart, onDragEnd, onDragOver, onDragLeave, onDrop, moveCard, and the `canWrite` / `moving` flags. Arguments: states ordered list of column state keys (strings) the board shows. labels optional {state: label}; falls back to the state key. empty_hints optional {state: {why, next_write, next_read}} shown when a column is empty, so an empty column names the next step instead of a grey block. can_write whether to render the drag handles and the "Move to" select. stage_group optional {state: group} where group is one of 'discovery' | 'execution' | 'done'; the header is tinted with a CSS custom property per group so a SAFe user recognises the discovery / execution / done bands. The ADM board passes none and keeps its own header colours. show_wip whether to render the WIP count / limit in the header. show_move whether to render the keyboard "Move to" select on each card. card_width Tailwind width utility for a column at phone width (the columns stay side by side and the region scrolls sideways). Built from the component macros: a column is a Card whose header carries the title and a Badge count, an item is a Card (kanban_card), the keyboard route is a "Move to" DropdownMenu (kanban_move_menu), and a polite live region announces a keyboard pick-up and drop. A card is picked up with Space or Enter, moved with the arrow keys and dropped with Space or Enter again.
