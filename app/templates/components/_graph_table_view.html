{#- The table alternative for a graph or chart: the same rows as the picture, as a table a keyboard and a screen reader can read. One per chart, included right after the chart: {% with chart_id='arbStatusChart', caption='Review status' %}{% include 'components/_graph_table_view.html' %}{% endwith %} `chart_id` is the id of the chart's (Chart.js) or of any element a script has registered rows for with GraphTableView.register(id, fn). `caption` names the table; it defaults to the chart's aria-label. Nothing here is drawn twice and nothing is fetched: the rows are read from the chart on the page, when the table is opened, so the table and the picture show the same numbers from the same request. Keyboard: the arrow keys move between cells, Home and End go to the ends of a row, Ctrl+Home and Ctrl+End to the first and last cell, Escape returns to the button. -#} {%- set _gtv_id = chart_id ~ '-table-view' -%}
