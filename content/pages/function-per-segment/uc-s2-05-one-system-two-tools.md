# When Jira and ServiceNow both know a system, treat it as one thing

**For scale-up CTOs running both Jira and ServiceNow.**

## The question

The same system exists as a Jira project and a ServiceNow configuration item, under two slightly
different names, with no link between them. Every question that reads "the system" has to guess
which record is authoritative.

## What Entelim is building

An identifier crosswalk that matches records across your connected tools automatically, routing
anything it isn't confident about to a review queue instead of guessing.
