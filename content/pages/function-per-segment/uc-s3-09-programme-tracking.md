# Is the programme on time and on budget, and what does each project touch?

**For programme managers and the enterprise architecture teams supporting them.**

## The question

A transformation programme has dates, a budget, and a list of projects. Whether it's actually on
track — and what each project is touching along the way — is usually spread across three different
tools that don't talk to each other.

## What Entelim answers

Ask about the programme, and get dates, status, and estimated-versus-actual cost for every project
in one place — with cost shown as genuinely missing where it hasn't been entered, never a silent
zero. A board view gives the programme lead the same projects by status.
