# What happens to my business if this person, supplier or system underperforms?

**For owner-operators running a services business, no architecture background needed.**

## The question

You're not an architect, and you don't want to become one. What you want is a straight answer to
a plain question: if this person leaves, this supplier drops the ball, or this system goes down,
what actually happens to the business?

## What Entelim answers

Ask it in plain words, and get an answer with the reasoning shown alongside it — never an estimate,
never notation you have to learn first. You pick a thing and ask what happens if it fails; that's
the whole interaction.
