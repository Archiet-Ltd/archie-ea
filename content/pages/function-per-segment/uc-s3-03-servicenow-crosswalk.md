# Resolve a ServiceNow CI to exactly one model element by shared identifier

**For enterprise architecture teams running ServiceNow as their CMDB of record.**

## The question

The same asset exists as a ServiceNow configuration item and a model element, under names close
enough to be confusing and different enough that nothing links them automatically.

## What Entelim is building

An identifier crosswalk, with low-confidence matches routed to a review queue instead of merged
blind, so ServiceNow and your model agree on what's the same thing without anyone guessing.
