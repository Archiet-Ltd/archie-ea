# ArchiMate in Entelim: the language your model is drawn in

ArchiMate is the Open Group's modelling language for enterprise architecture. It describes an organisation in layers: strategy, business, application, technology and physical, with motivation elements such as goals and requirements across them, and implementation elements such as work packages and plateaus. Each thing is an element of a defined type, and the links between elements have defined meanings. That precision is what lets a model answer questions.

## Who uses ArchiMate, and when

ArchiMate suits anyone who needs to describe how business, applications and technology fit together and be understood by other people. Enterprise and solution architects use it most, but business analysts and security architects use it to show what depends on what. Its value is that every element has a defined type and every link a defined meaning, so two people reading the same model read the same thing. Entelim uses it throughout, which means imports from other ArchiMate tools arrive in a form the model already understands.

## How Entelim loads ArchiMate at sign-up

Choose ArchiMate on the company step of sign-up, or adopt it later in Settings, and Entelim adopts the framework as a list of its layers and element groups: Strategy, Business, Application, Technology, Physical, Motivation, and Implementation and migration. The list appears on the Frameworks page. Entelim's own model already uses ArchiMate element types, so adopting it is a guide to the structure rather than a second copy of the model.

## What you get

- The ArchiMate layers listed on the Frameworks page, each with what it contains.
- An architecture model you can browse by layer, filter and count.
- Diagrams drawn from the elements in the model, so the picture and the data cannot disagree.
- Import of an ArchiMate file, to start from a model you already have.

## How to use it

1. Tick ArchiMate at sign-up, or adopt it from Settings.
2. Open the architecture model and browse it layer by layer.
3. Import an existing ArchiMate file if you have one, and check the elements it brings in.
4. Add what is missing as elements of the right type rather than as notes.
5. Draw a diagram from the elements, and open any element in it to see what it is linked to.

## Common mistakes

The usual mistakes are using elements loosely, so that a business service and an application service are confused, and drawing diagrams that cannot be traced to the model. Pick the element type that matches what the thing is, and let the diagram be a view of the model rather than a separate drawing.

## Why Entelim is different

In most tools a diagram is a drawing and the data is somewhere else. In Entelim the elements are records and a diagram is a view of them, so changing an element changes every diagram that shows it. Connect GitHub or Jira at sign-up and the application layer starts from what you already run. The AI chat answers from the model and cites the elements it used.
