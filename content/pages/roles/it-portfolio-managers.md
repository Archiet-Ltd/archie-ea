# IT portfolio manager software for a portfolio you can defend at budget time

IT portfolio manager software earns its place by turning a list of applications into a decision: what
to keep, what to retire, and what each choice saves. Entelim scores every application against the TIME
model, flags likely duplicates, and turns the result into a consolidation list with a target date, a
saving and an owner on every entry. It is built for the portfolio manager who reports the shape of the
application estate to the CIO, and a team can start on the free Community plan.

**[Start free](/register)** or **[see pricing](/pricing)**.

## What an IT portfolio manager does

An IT portfolio manager is accountable for the shape of the application estate: how many applications
the organisation runs, what each one costs, who owns it, and which of them to keep, replace or retire.
The job exists because that list drifts on its own — two teams buy the same tool without telling each
other, a contract renews that almost nobody still uses, an application outlives the one person who
could explain what it does. Portfolio manager software earns its place by turning that drift into a
reviewable decision: a score, a reason and a saving attached to every application, rather than a
spreadsheet nobody fully trusts.

## Limits

Entelim does not discover applications on your network; the inventory is what you enter or import.
Duplicate detection proposes candidate groups from recorded names and attributes, and a person decides
what is genuinely the same tool — nothing is merged or retired until someone approves it. Savings and
payback on a replacement plan are the figures you enter, not an estimate Entelim produces from market
prices. A score is only as strong as the fields behind it: an application missing its owner, cost or
risk is flagged as having insufficient evidence instead of given a confident number.

## Frequently asked questions

### What is the TIME model?

The TIME model sorts every application into Tolerate, Invest, Migrate or Eliminate. Entelim scores each
one on technical health, business value, cost efficiency and vendor risk, assigns the TIME
recommendation, and maps it to an action: retain, refactor, replace, retire or consolidate. You can
override the recommendation and record why.

### Can I import our application spreadsheet?

Yes. Add applications one at a time, or import a CSV or Excel spreadsheet with a preview before anything
saves, an import history, and a rollback if the import was wrong. If your applications already live in
an ArchiMate model instead, import that directly.

### How are portfolio KPIs calculated?

Each score reads from a named formula: four weighted inputs — technical health, business value, cost
efficiency and vendor risk — that must add up to one before a new version can go live. A portfolio
manager can open a new version with different weights, and a past figure stays attached to the version
that produced it, so the number behind a KPI is never a mystery.
